# SDF Modeling for Digital Twin

This repository contains the source for the ASDF Working Group Internet-Draft:

**Semantic Definition Format (SDF) Modeling for Digital Twin**

- Datatracker: https://datatracker.ietf.org/doc/draft-ietf-asdf-digital-twin/
- Working Group: https://datatracker.ietf.org/wg/asdf/about/
- Mailing list: https://mailarchive.ietf.org/arch/browse/asdf/

## Source file

The authoritative source is:

```text
draft-ietf-asdf-digital-twin-04.xml
```

Generated `.txt` and `.html` files are build artifacts and should not normally be edited directly.

## Build locally

Install `xml2rfc` and run:

```bash
python -m pip install --upgrade xml2rfc
make
```

This creates:

```text
draft-ietf-asdf-digital-twin-04.txt
draft-ietf-asdf-digital-twin-04.html
```

To remove generated files:

```bash
make clean
```
